# Kumpulan Soal Latihan dan Jawaban Python (Pertemuan 1-19)

Pendamping Modul Pembelajaran Python Dasar sampai Menengah.

## Struktur

```
pertemuan_NN_judul/
    soal_latihan.py          <- soal + ruang menulis jawaban
    jawaban/
        jawaban_NN_soalK.py  <- kunci jawaban soal ke-K (dapat dijalankan sendiri)
```

## Cara pakai

1. Buka folder pertemuan, kerjakan soal di soal_latihan.py.
2. Bandingkan dengan file di folder jawaban/.
3. Jalankan jawaban dari DALAM folder jawaban/ (beberapa soal memakai file nilai.csv / catatan.txt yang sudah disediakan di pertemuan 12 dan 19).
4. Banyak soal memakai input(): ketik masukan saat diminta.
5. Beberapa jawaban pertemuan 11 (konversi.py dan utama.py) dan pertemuan 18 (unit test) harus dijalankan dari folder yang sama dengan file modulnya.
